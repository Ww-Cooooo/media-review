# 0.3.0-beta.11：多个 Agent 共用桌面入口

默认资料库只维护一个 Media Review 桌面图标。对话、Agent、安装位置和启动参数变化不再生成随机后缀图标；并发初始化串行维护同一个入口。相同版本复用完整可用副本，新版本更新入口；使用新版入口逻辑的旧版本调用不会降级健康入口。旧副本缺失或损坏时改用完整副本。

独立资料库默认不新建图标。明确需要专用入口时，使用 `--desktop-name "Media Review - 项目名称"`；同名不同资料库和无关图标不会被覆盖。现有任务、意见、媒体和字幕工具不迁移、不删除。

旧安装不会自动升级。请让各宿主的 Agent 更新所用 Skill，或在新目录安装本版并切换到新入口；尚未更新的旧安装器仍可能新增随机图标。本版日常启动不会自动删除旧图标，整理前需核对资料库并备份。

验证包括 Windows 原生快捷方式、跨副本并发初始化、任务隔离、版本变化和不兼容服务保护。完整 ZIP 和 SHA256SUMS.txt 随本预发布版提供。
