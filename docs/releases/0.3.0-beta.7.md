# 0.3.0-beta.7：标记更易修正，启动先检查再复用

本版继续支持 Windows 10/11 x64，仍为预发布版。

- 时间选错可直接清空；当前意见的全部标记可一键清空并恢复，共用文字保留。
- 框选期间写好意见即可直接保存。完成框选使用绿色，取消和删除使用红色；各框显示“框 N ×”，撤回／恢复按钮明确只针对画面框操作。
- 首次使用由 Agent 先说明可能联网准备的运行组件、音视频工具和模型，再检查已有环境。全缺时约下载 0.8 GB，用户不用自行下载或配置。
- 以后打开先核对实际路径和工具能否运行；有效工具、模型与匹配的真实字幕测试结果直接复用。旧路径失效先找已知可用位置，只补缺项，不因新对话或旧回执缺失重装整套环境。
- 桌面入口执行相同检查，匹配的快捷方式和页面启动协议不重复改写。修正启动准备失败却返回成功的问题。

已验证真实中文样本的波形、字幕和时间码，连续打开及失效路径恢复未重复下载；前一轮标记操作经过真实浏览器验证。自动测试与完整包构建通过。这些检查不代表所有宿主、电脑或用户素材均已验收。

下载本页的 `media-review-0.3.0-beta.7-windows.zip`，核对 `SHA256SUMS.txt` 并完整解压；让 Agent 按包内说明安装或更新。只安装仓库 `skill/` 的宿主会从本版 Release 补齐完整程序。升级前保存意见并保留现有安装和私有资料；已有自选模型与本机定制应先比较、再合并。旧版不会静默自动更新。
