# 0.3.0-beta.9：先写意见，需要时再逐框补充

此前虽然只有一个输入框，“统一说明”和各个框仍并列成选项，用户需要先判断该在哪里写；选中画面框也会改变正在编辑的内容。本版调整这一流程：

- 默认固定显示“填写意见”，直接写即可，适用于本条全部标记。框选、选择和移动画面框不再切换填写目标。
- 不同框需要不同说明时，再点“分别给各框补充说明（可选）”。页面明确显示“正在补充：框 N”，可切换编号或返回整条意见；切换保留文字，已有补充显示数量。
- 主意见、各框补充一起保存。只填写其中一处也可以，不要求重复填写或填满所有框。
- 框号定位和叉号删除集中在“画面标记”区。删框不重排编号，撤回删框保留已写文字，已有记录无需迁移。
- Skill 和使用说明同步更新，避免 Agent 把主意见与逐框补充解释成两份必填表单。

已在 Windows Edge 的 1366×768、1440×900 视口检查横屏和竖屏：默认填写、三框补充、画面选择、返回主意见、删框撤回、保存后重开、只填逐框说明、快捷保存，以及尚在框选时直接保存。构建通过，76 项现有测试通过。以上为创建者实测，不代表用户已验收，也不新增其他宿主或平台保证。

本轮保留已有依赖准备和字幕流程；没有重新下载模型。升级前请保存其他窗口的输入。完整包与 SHA256 校验文件随本预发布版提供；已有安装不会自动升级。
