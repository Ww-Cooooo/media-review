# 0.3.0-beta.10：画一个框，就在旁边写意见

画框后立即出现贴边浮卡，写完点“完成”，直接继续拖下一个框。每个新框都有明确对应的意见；全部写好后一起保存。

- 采用贴边浮卡与虚线角标框，待填写用琥珀色、已填写用绿色，分组并显示文字与数量。
- 浮卡会换边避开当前框；大框或窄窗口放不下时移到画面下方。长意见在卡内滚动，完成和删除按钮保留。
- 支持连续绘制、重叠框、稳定编号、任意删除与撤回；空框提示补写或删除。全部已填写时无需逐个再次完成即可总完成或保存。
- 画框前的整条意见与旧版记录继续保留；卡片完成与正式保存清楚区分。时间段、独立参考帧、草稿恢复和原有放大／全屏保留。
- 修正放大／全屏大框的浮卡位置振荡，以及窄窗口下放大按钮图标被隐藏的问题。
- Skill 指引同步为新操作方式，解释旧记录兼容、稳定框号及各框文字的返修对应关系。

验证：79 项自动检查通过；Windows Edge 中检查连续绘制、重叠与边缘、长意见、横竖屏、窄窗口、放大／全屏、删除恢复、正式保存、草稿恢复及无框意见。完整安装包独立启动并复测。未将浏览器测试当作实机触屏、所有宿主或用户审美验收。

升级前保存当前工作并保留旧包与数据；旧安装不会自动更新。本轮不重新安装识别器或模型。浮卡“完成”只收起本框，正式保存成功后才写入意见记录。
