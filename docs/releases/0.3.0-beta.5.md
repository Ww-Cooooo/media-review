# Media Review 0.3.0-beta.5

这一版把“边看边记问题 → 逐条返修 → 新版复核”接成连续流程。仍为 Windows 预发布版。

## 标记与校对

- 可以先标起点、继续观看、再标终点；时间段与独立参考帧、多区域框选共存。
- 画面框有稳定编号，可分别写说明、点击联动、删除任意框、撤销和重做；删除不重排编号，几何撤销保留文字。
- 支持整片意见、无意见完成审阅、误删意见恢复；常用笔记本尺寸下播放与输入同屏。
- I/O 标起终点，细步定位、带上下文回放；意见可搜索、筛选，N 跳到下一条问题。浏览器定位不承诺逐帧精度。
- 支持搜索字幕、导入并按任务保存 UTF-8 SRT/VTT。

## 返修与管理

- 意见性质与处理进度分开：待处理、待澄清、已修改待复核、用户确认；用户可以重新打开问题。
- 同作品版本关联，显示 V1/V2 与本版处理内容；已结束旧版可只读查看。旧时间码、截图和框仍属于原版。
- 完成审阅固定本轮意见快照；Agent 接手回执、处理结果和自检报告绑定明确任务及修订。Agent 不替用户确认。
- 任务支持全量搜索、筛选、排序、重命名、批量归档和恢复；正在使用的任务跳过归档。
- 保存与恢复冲突按意见比较文字、时间和画面，可逐条选择后明确保存。
- 导出可直接阅读的 HTML、Markdown、带编号框的 SVG，同时保留原图与结构化意见及进度。
- 自检可按修改位置补取帧，记录实际检查范围、发现、未核实部分和保留项；取帧成功不等于完整观看或试听。
- 本机可用性显示运行版本、定制信息、宿主接入线索和工具缺项。保留 beta.4 的小电视启动图标与安装检查。

## 安装与升级

下载本发布页的 `media-review-0.3.0-beta.5-windows.zip`，核对 `SHA256SUMS.txt`，完整解压后运行“安装 Media Review.cmd”。需要 Node.js 24+、PowerShell 7+ 和浏览器；源码 ZIP 不能代替完整安装包。

安装器默认安装到当前用户的 `.claude/skills/media-review`。Codex 或其他宿主可用 `scripts/install.ps1 -Destination "<宿主的 skills 目录>\media-review"` 指定完整目标目录。不同版本不会静默覆盖；先保存、备份，再按[升级说明](https://github.com/Ww-Cooooo/media-review/blob/v0.3.0-beta.5/docs/install-windows.md)采用新版。

新意见使用 v5，恢复副本使用 v4；旧格式可读，首次升级保存前保留旧字节。安装不批量转换旧资料，不改写原媒体。回退前保留新意见、快照、字幕和返修进度，不以旧备份覆盖新增内容。

FFmpeg、语音识别器和模型仍为可选依赖，不随包自动下载；缺少时可手动校对和导入字幕。
