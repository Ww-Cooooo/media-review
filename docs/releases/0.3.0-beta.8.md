# 0.3.0-beta.8：意见只在一个地方填写

此前“你的意见”和各框说明同时出现，用户容易不知道该填哪处，保存按钮也夹在两组输入之间。

- 统一为一个填写区，选择“统一说明”或具体框号，同一时间只显示一个输入框。
- 任选一处填写即可保存；切换对象保留各自文字，有文字的项目显示圆点。保存时整条意见一起写入。
- 原有统一意见与各框说明都保留；只写各框的旧意见会定位到已有文字，系统摘要不会被误当成用户输入。
- 删除框、撤回删除、画面与文字联动继续可用。收起选定位置后的重复提示，减少小屏幕输入区的占用。

数据格式、依赖和首次启动流程均未变化。更新前先保存当前意见，比较并保留本机定制；旧版不会静默自动更新。

下载本页的 `media-review-0.3.0-beta.8-windows.zip` 与 `SHA256SUMS.txt`，完整解压后让 Agent 按包内说明更新。仅安装仓库整个 `skill/` 的宿主会取得本版完整程序。
