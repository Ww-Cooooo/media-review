# Media Review

**AI 出片之后，把“哪里要改”说清楚。**

Media Review 是一个本机音视频校对室，也是一套供 Agent 使用的 Skill。已接入这套流程、具备本机执行权限的 Agent，在第一版或返修版导出后主动送片、排队自检。你回来时从任务列表接手，边看视频或听录音，边在具体时间和画面位置留下意见，再把这一轮交给 Agent 返修。

它把“这里不对”变成有时间、位置和参考画面的反馈，减少来回描述。它不替代剪辑软件，也不会直接改写原视频；实际返修仍由你的 Agent 或剪辑人员完成。

## 开始使用

当前版本为 **0.3.0-beta.10 Windows 预发布版**，完整安装包见 [本版发布页](https://github.com/Ww-Cooooo/media-review/releases/tag/v0.3.0-beta.10)。画一个框，旁边就出现对应意见卡；写完点“完成”，直接继续拖下一个框。待填写和已填写分组、分色显示，全部写好后一起保存。首次准备先说明，后续打开先检查已有环境，只补缺项。连续标注、多区域意见、逐条返修和版本复核继续保留。旧版安装不会自动更新。

### 下载安装（Windows）

使用 **Windows 10/11 x64**、Edge 或 Chrome，以及能运行本机命令的 Agent。将本仓库地址交给 Agent 安装 `media-review` Skill，然后说“打开音视频校对台”。Agent 会先说明可能需要联网下载和配置什么，再检查本机，补齐缺少的运行环境、识别器和语音模型，实测后打开网页；用户不用寻找工具或填写路径。首次全缺时约下载 0.8 GB，建议留出 2 GB 空间。

也可以下载 [完整 ZIP](https://github.com/Ww-Cooooo/media-review/releases/download/v0.3.0-beta.10/media-review-0.3.0-beta.10-windows.zip)，全部解压，双击“安装 Media Review.cmd”。它默认安装到 Claude Skill 目录并完成同一准备流程；其他宿主由 Agent 指定对应目录。工具保存在校对台自己的私有目录，不需要管理员、不修改系统 PATH、不开机自启。下载期间只获取依赖，不上传用户音视频。

准备成功后网页自动打开，选择视频或音频即可生成字幕、标记时间并保存意见。以后通过 Agent 或桌面入口打开，都会先检查实际工具路径和可用性；能用就复用，不重复安装，工具未变化也不重复跑字幕测试。准备好后通常可离线使用，文件缺失、失效或明确升级时才可能再次下载。[完整安装及旧版升级说明](docs/install-windows.md)。

**安装 Skill 时保留整个 `skill/` 目录，不能只复制 SKILL.md。** 宿主只取得这个目录时，首次入口会自动补齐对应版本的完整运行包；开发源码的 ZIP 仍不等于已构建应用。

### 从当前源码运行

需要 Node.js 24+ 与 npm；官方 Node.js 安装版应保留 npm 组件。若你取得的是源码 ZIP，先完整解压，打开包含 `package.json` 的项目文件夹。Windows 用户可在资源管理器地址栏输入 `cmd` 并回车，在该文件夹打开终端；先用 `node --version`、`npm --version` 确认命令可用，再依次执行以下命令。安装 npm 依赖需要网络：

```sh
npm ci --ignore-scripts
npm run build
npm start
```

`npm start` 会启动或复用本机服务并打开浏览器。也可以在构建后双击根目录的“打开 Media Review.cmd”。选择浏览器能播放的素材，即可开始手动校对；无需先安装 FFmpeg 或语音模型。

## 一轮校对怎样完成

1. **Agent 出片并自检。** 成片写入完成后，Agent 调用入口带入这一版，在自己的工作循环中看画面、听声音、核对字幕与节奏。工具证据和用户意见分开保存。
2. **边看边留下意见。** 先标起点，继续看，结束时再标终点；同一条意见可附参考帧和多个编号框，分别填写说明，也能直接写整片意见。“修改／保留／待讨论”表达你的意图。
3. **完成审阅并交接。** 单条意见保存回读成功后进入新意见。整轮完成会固定本次意见版本；没有问题也能明确完成。复制交接内容，回到能访问本机文件的 Agent 聊天，粘贴并发送。
4. **逐条返修，再看新版。** Agent 读取固定的本轮意见及参考图，登记处理结果，另行输出关联的新版本。你在“版本与返修”中查看 V1/V2、逐条复核或重新打开问题；旧时间码和画面框仍属于原版，原媒体与旧意见保留。

**保存、复制、发送是三个不同动作。** 只保存或复制，不会自动开始返修、上传或发布。taskId与来源标签帮助辨认任务，但不绑定或唤醒原聊天；请把交接内容发送到负责这项任务的Agent对话。应用没有整片认可或发布按钮，是否认可、是否允许发布，以用户另行明确表态为准，不能由“保留”意见或结束任务代替。

通过其他软件制作的成片也可以手动选择；没有 Agent 时，仍可交给剪辑人员处理。先正式保存这一轮，关闭交接弹窗返回当前素材，再点击右侧意见栏底部的“导出返修资料包”。导出弹窗会给出实际文件夹位置，复制到资源管理器即可找到；把整个资料文件夹交给对方，并另行提供正确源媒体。**这个界面操作不需要查找媒体指纹**，保存文件夹也不等于已导出的资料包。

## 连续校对更顺手

任务可以搜索、筛选、重命名、归档和恢复；意见可按关键词、类别和处理进度查找。I/O 标起终点，N 跳到下一条问题；字幕支持搜索及导入 SRT/VTT。画面框可按编号删除、撤销和重做，误删意见也可恢复；保存冲突按文字、时间和画面逐条比较。

导出的 `返修清单.html` 可直接阅读，图片上带编号框和对应意见，同时保留原图与结构化记录。常用笔记本尺寸下，播放、标记和意见输入可同屏操作。操作方法见[完整使用说明](skill/README.md)，Agent 的接手、进度和自检方法见[返修流程](skill/references/repair-loop.md)。

## 接进 Agent 的出片流程

Agent 需要能在本机读取文件、执行命令；纯网页聊天界面本身不能启动你的电脑程序。宿主是否自动发现 Skill 由宿主负责，不等于放入文件就一定会自动调用。

从**源码项目根目录**执行：

```sh
node scripts/review-agent.mjs after-export --media "<本轮成片的绝对路径>" --request-id "<本轮固定UUID>" --label "<来源短标识>"
```

从**已完成首次准备的 Windows Skill 目录**执行：

```sh
scripts\review.cmd after-export --media "<本轮成片的绝对路径>" --request-id "<本轮固定UUID>" --label "<来源短标识>"
```

将占位符替换为实际导出的文件路径。入口启动／复用同用户、同数据根的兼容服务，返回独立 `task.id` 并排队自检；排队不是已经检查完成。记录这个 taskId 和 `inspection.id`，用 `status --task "<taskId>" --job "<inspection.id>" --result`查询这次实际结果。同一次调用重试可提供相同的 `--request-id "<UUID>"`；不同版本或独立意图使用新 UUID，`--label`可标明来源。

**送片不等于再开一页。** 当前服务首次自动请求打开浏览器，之后只送到任务列表，不切走正在校对的片。不要让 Agent 收到网址后再调用浏览器工具新建窗口；给用户本轮定位入口时应返回`taskUrl`及本机启动入口，而不是把共用`url`当作本对话的任务地址。beta.3可用`open --task "<taskId>"`重开指定已有任务，不另建任务；专属链接在次窗口也按指定任务打开，已有编辑窗口时仍须明确只读或接管。入口无法强制聚焦既有浏览器标签，也不能强制所有宿主遵从 Skill 文本。流程、异步回执与自检边界见 [Skill 正文](skill/SKILL.md)和[Agent 接入说明](docs/agent-workflow.md)。

## 校对时可以做什么

- **准确指出位置：** 时间点、共同时间段、当前帧区域分别标记；截图属于独立参考帧，不把区间起点冒充截图时间。
- **继续看、继续写：** 播放不改变意见目标，旧框不持续覆盖画面；已有意见先查看定位，主动点击修改才编辑。
- **放大或全屏看视频（beta.3）：** 播放条右侧可页内放大或进入浏览器全屏，按Esc或“收起”返回。沿用同一个播放器，保留位置、播放速度和意见；浏览器拒绝全屏时提供页内放大。
- **找回工作：** 首页查看历史、意见 JSON、参考图和草稿位置；桌面入口按需重开服务，已确认的恢复副本帮助继续校对。
- **把反馈交给其他人：** 导出可读清单、结构化意见与相对路径参考图，不默认附带原视频、其他轮次或自动执行授权。

## 可选分析工具

| 本机工具 | 提供的能力 | 缺少时 |
| --- | --- | --- |
| FFmpeg／FFprobe | 真实 RMS 波形、解码检查、代表帧和条件黑场／静音检测 | 手动播放、标注、保存和交接仍可用；相应分析明确不可用 |
| whisper.cpp CLI 与 GGML `.bin` 模型 | 本机语音转写与台词定位索引 | 可以按画面、声音和时间手动定位 |

这些工具和模型由首次入口自动准备，固定来源、版本和校验值见[依赖说明](skill/references/dependency-sources.md)。缺少工具或配置变化时，Agent 重新运行首次入口恢复；网络受限时，手动校对仍可用。自动转写需要回听校正；取帧、解码通过不等于全片观看、美感或听感验收，也不等于用户认可。

## 数据与恢复

应用不内置云端上传或遥测，音视频分析由本机工具完成。若你把截图或交接内容交给云端 Agent，其数据处理取决于所用宿主与服务，不能把应用的本机处理描述成所有 AI 推理都在本机。

默认私有数据位于当前用户主目录下的 `.media-review-desk/data`。历史目录名保留是为了兼容已有数据，与程序源码分开：

- `tasks/<taskId>/`：每个新任务的身份、独立正式意见、参考图与窗口恢复副本；历史版本和恢复归档不代表用户认可。
- `reviews/`、`inbox/`：兼容保留的旧版资料。旧 current 那项进入等待，其余旧交接需明确选择继续；不会凭多个旧登记自动拆分过去共用的意见。
- `jobs/`、`analysis-cache/`：有界分析登记与可重建缓存，回收后可以明确重试；不是正式意见目录。
- `self-checks/`：保留的 Agent 证据，与用户意见分开，不自动当缓存删除。
- `exports/`：主动导出的私有返修资料包。

服务只监听 `127.0.0.1`，私有接口使用同源请求和进程内令牌；令牌不写网址。不要把服务暴露到公网，也不要把上述私有目录放进仓库。更多边界见 [安全与隐私说明](SECURITY.md)。

不同任务不会合并意见。同一任务默认一个编辑窗口，其他窗口需明确选择只读或接管；保存还要核对加载时的意见版本，陈旧内容不能直接覆盖后来保存的版本。冲突时可比对并明确选择以本页为准，服务保留被替换的正式旧版。恢复副本的基线变了，也需比对后选择，不自动拼接采用意图。

暂时断线时保留当前输入，不要刷新有未保存内容的旧页；从桌面入口重新启动后，页面先核验新会话。Agent 登记的原文件可重新带入；已移动的文件可从任务列表“手选同版”，手选素材本来就需重选。最后未确认输入、清除浏览器数据、源文件变化或未知端口占用，不能保证零损失。

### 页面重启与本机启动入口（beta.3）

服务在线时可从“任务操作 → 重启校对服务”核对全部窗口、分析和未保存输入，再明确重启；新会话通过真实身份与认证检查后才恢复连接。断线后，页头连接状态右侧显示“重启服务”；它与下方断线提示内的“启动 Media Review 本机校对室”使用同一个已配置入口，请求Windows唤起固定的Node.js启动入口，不刷新旧页、不默认另开浏览器；原端口被占用时可能打开新地址，旧页输入仍须保留。这不是网页直接执行任意本机命令。

安装器默认注册当前用户、按资料根隔离的专用启动协议；不需管理员、不增加常驻启动器或开机自启。浏览器可能要求确认，系统可能显示Node.js或未知发布者，不能保证所有安全软件放行。入口用途、跳过／取消登记与安全软件拦截说明见[Windows安装说明](docs/install-windows.md)和[启动入口说明](skill/启动入口说明.txt)。公开beta.2不包含本节功能。

### 看见正在分析的素材（beta.3）

有活动分析时，页面左下角显示可收起的浮动提示，标明素材、实际处理阶段、所属校对任务与本机服务；排队、等待资源和上传分别显示。点击素材先核验当前状态，再请求定位已打开的对应校对页；浏览器未允许切页或原页不响应时，可在本页安全定位，不默认另开浏览器、抢编辑权或取消其他分析。仅展示本服务已登记的对象，不扫描整机网页或其他程序；旧入口未登记来源时明确说明，不能编造归属。

## 当前限制

- 当前交付目标是 Windows 桌面测试版；其他系统的一键安装、另一台电脑的兼容性和所有宿主的自动发现没有经过同等验证。
- 自动带入及分析原文件上限 1 GiB，解码 PCM 暂存上限 512 MiB，超过时仍可手选播放和标注；30 分钟以上不自动整段转写。
- 同数据根最多一个重分析执行，活跃队列最多32项、上传暂存最多2份；资源不足时排队或明确拒绝，不结束整个校对室。各工具显式线程参数上限4，不是操作系统CPU／总线程硬限制。详细磁盘预算见[开发说明](docs/development.md)。
- 时间以当前文件自身 0 秒为起点，浏览器定位不是帧级或采样级保证；精确剪点需回源核对。
- 待人工任务、窗口或分析存在时不按旧30分钟／4小时规则退出；只有真正空台默认宽限10分钟回收。没有开机自启，崩溃或电脑重启后仍需运行启动入口。挂起释放本页媒体但任务继续等人，结束任务不是认可或删除，全局退出需明确确认。
- 不兼容旧版不能混用同一数据根；新入口不会自动结束它。beta.1可能已有未登记的重复服务，不能仅凭一个session文件宣布它们全部退出，升级步骤见[安装说明](docs/install-windows.md)。
- 页面的 File／Blob、冻结标签和浏览器自身开销受浏览器管理，应用不能远程强制清空其物理内存。4K长片峰值、真实休眠／重启和24小时耐久尚未形成同等实测保证。
