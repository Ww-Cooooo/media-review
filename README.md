# Media Review

**AI 出片之后，把“哪里要改”说清楚。**

Media Review 是一个本机音视频校对室，也是一套供 Agent 使用的 Skill。已接入这套流程、具备本机执行权限的 Agent，在第一版或返修版导出后主动打开校对室、带入成片，并在制作循环中自检。你可以边看视频或听录音，边在具体时间和画面位置留下意见，再把这一轮交给 Agent 返修。

它把“这里不对”变成有时间、位置和参考画面的反馈，减少来回描述。它不替代剪辑软件，也不会直接改写原视频；实际返修仍由你的 Agent 或剪辑人员完成。

## 开始使用

当前版本为 **0.3.0-beta.1（Windows 测试版）**，建议先小范围试用，不作为稳定版承诺。

### 下载安装（Windows）

准备 **Node.js 24+、PowerShell 7+（命令为 `pwsh`）和支持素材编码的浏览器**，推荐 Microsoft Edge 或 Chrome。未安装运行环境时，可从 [Node.js 24 官方下载目录](https://nodejs.org/dist/latest-v24.x/)选择 Windows `.msi` 安装版，并按 [微软官方说明](https://learn.microsoft.com/zh-cn/powershell/scripting/install/install-powershell-on-windows)安装 PowerShell 7；详细选择与检查方法见[安装说明](docs/install-windows.md)。

从 [v0.3.0-beta.1 发布页](https://github.com/Ww-Cooooo/media-review/releases/tag/v0.3.0-beta.1)下载 `media-review-0.3.0-beta.1-windows.zip`。**代码页的“Download ZIP”和发布页的“Source code”都是源码，不是完整安装包。** 将 Windows 安装 ZIP 完整解压，双击其中的“安装 Media Review.cmd”。安装器会安装 Skill，并创建“Media Review”桌面入口；不需要管理员权限，不自动下载软件或注册开机启动。

安装完成后双击桌面图标，选择一段视频或音频，标记时间点并保存第一条意见。首页“校对历史”能看到这份记录和实际保存位置。[完整安装说明](docs/install-windows.md)。

**请保留完整包，不能只复制 SKILL.md。** 源码仓库的 `skill/` 是打包模板，不是已经包含运行程序的安装包。

### 从当前源码运行

需要 Node.js 24+ 与 npm；官方 Node.js 安装版应保留 npm 组件。若你取得的是源码 ZIP，先完整解压，打开包含 `package.json` 的项目文件夹。Windows 用户可在资源管理器地址栏输入 `cmd` 并回车，在该文件夹打开终端；先用 `node --version`、`npm --version` 确认命令可用，再依次执行以下命令。安装 npm 依赖需要网络：

```sh
npm ci --ignore-scripts
npm run build
npm start
```

`npm start` 会启动或复用本机服务并打开浏览器。也可以在构建后双击根目录的“打开 Media Review.cmd”。选择浏览器能播放的素材，即可开始手动校对；无需先安装 FFmpeg 或语音模型。

## 一轮校对怎样完成

1. **Agent 出片并自检。** 成片写入完成后，Agent 调用入口带入这一版，在自己的工作循环中看画面、听声音、核对字幕与节奏。工具证据和用户意见分开保存。
2. **你在具体位置留下意见。** 标记时间点、选择共同时间段，或框选当前画面，写下“修改／保留／待讨论”。时间段可同时涉及画面、声音、字幕和节奏，不只是声音段。
3. **保存并交接。** 单条意见写入并回读成功后进入空白新意见。整轮完成点击“保存并交给 Agent”，包含最后一条完整草稿；复制弹窗内容，回到能访问本机文件的 Agent 聊天，粘贴并发送。
4. **Agent 按实际请求返修。** Agent 读取当次意见及参考图，另行输出新版本，再带入校对室。原媒体、已有成片和旧意见不应被覆盖。

**保存、复制、发送是三个不同动作。** 只保存或复制，不会自动开始返修、上传或发布。

通过其他软件制作的成片也可以手动选择；没有 Agent 时，仍可交给剪辑人员处理。先正式保存这一轮，关闭交接弹窗返回当前素材，再点击右侧意见栏底部的“导出返修资料包”。导出弹窗会给出实际文件夹位置，复制到资源管理器即可找到；把整个资料文件夹交给对方，并另行提供正确源媒体。**这个界面操作不需要查找媒体指纹**，保存文件夹也不等于已导出的资料包。

## 接进 Agent 的出片流程

Agent 需要能在本机读取文件、执行命令；纯网页聊天界面本身不能启动你的电脑程序。宿主是否自动发现 Skill 由宿主负责，不等于放入文件就一定会自动调用。

从**源码项目根目录**执行：

```sh
node scripts/review-agent.mjs after-export --media "<本轮成片的绝对路径>"
```

从**已安装的完整 Skill 目录**执行：

```sh
node scripts/review.mjs after-export --media "<本轮成片的绝对路径>"
```

将占位符替换为实际导出的文件路径。入口会启动或复用服务、登记明确指定的媒体、打开校对室并生成独立 Agent 自检资料；它不是对任意剪辑软件的后台监控，也不会安装全局 hook。流程要求和返修边界见 [Skill 正文](skill/SKILL.md)与[Agent 接入说明](docs/agent-workflow.md)。

## 校对时可以做什么

- **准确指出位置：** 时间点、共同时间段、当前帧区域分别标记；截图属于独立参考帧，不把区间起点冒充截图时间。
- **继续看、继续写：** 播放不改变意见目标，旧框不持续覆盖画面；已有意见先查看定位，主动点击修改才编辑。
- **找回工作：** 首页查看历史、意见 JSON、参考图和草稿位置；桌面入口按需重开服务，已确认的恢复副本帮助继续校对。
- **把反馈交给其他人：** 导出可读清单、结构化意见与相对路径参考图，不默认附带原视频、其他轮次或自动执行授权。

## 可选分析工具

| 本机工具 | 提供的能力 | 缺少时 |
| --- | --- | --- |
| FFmpeg／FFprobe | 真实 RMS 波形、解码检查、代表帧和条件黑场／静音检测 | 手动播放、标注、保存和交接仍可用；相应分析明确不可用 |
| whisper.cpp CLI 与 GGML `.bin` 模型 | 本机语音转写与台词定位索引 | 可以按画面、声音和时间手动定位 |

安装包不包含这些工具或模型，也不自动下载。安装器可显式绑定已有文件，[安装说明](docs/install-windows.md)列出参数。自动转写需要回听校正；取帧、解码通过不等于全片观看、美感或听感验收，也不等于用户认可。

## 数据与恢复

应用不内置云端上传或遥测，音视频分析由本机工具完成。若你把截图或交接内容交给云端 Agent，其数据处理取决于所用宿主与服务，不能把应用的本机处理描述成所有 AI 推理都在本机。

默认私有数据位于当前用户主目录下的 `.media-review-desk/data`。历史目录名保留是为了兼容已有数据，与程序源码分开：

- `reviews/`：正式意见、参考图及恢复副本；恢复副本不代表正式保存。
- `inbox/`：Agent 明确登记的源文件本机路径绑定，不复制原媒体。
- `self-checks/`：Agent 证据，与用户意见分开。
- `exports/`：主动导出的私有返修资料包。

服务只监听 `127.0.0.1`，私有接口使用同源请求和进程内令牌；令牌不写网址。不要把服务暴露到公网，也不要把上述私有目录放进仓库。更多边界见 [安全与隐私说明](SECURITY.md)。

掉线后当前输入保留，页面另用浏览器 IndexedDB 补充恢复。请不要关闭或刷新有未保存意见的旧页，从桌面重新打开。Agent 带入的文件可自动重开；手选文件需重新选择同一文件再恢复。最后未确认的输入、清除浏览器数据、原文件变化或端口被占用时，不能保证零损失，也不提供任意多窗口并发保存的冲突保证。

## 当前限制

- 当前交付目标是 Windows 桌面测试版；其他系统的一键安装、另一台电脑的兼容性和所有宿主的自动发现没有经过同等验证。
- 浏览器必须支持素材编码。自动带入及本机分析单文件上限 1 GB，更大文件可手动选择；30 分钟以上不自动整段转写。
- 时间以当前文件自身 0 秒为起点，浏览器定位不是帧级或采样级保证；精确剪点需回源核对。
- 服务默认 30 分钟无实际操作或最长 4 小时关闭；心跳不使它永久常驻，再双击入口即可按需启动。
