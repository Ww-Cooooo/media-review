# Agent 首次准备与恢复

目标：用户装好 Skill 并提出使用请求后，由 Agent 完成运行包、工具、模型、测试和开页；不要让用户自行寻找下载链接、敲命令或填写工具路径。适用 Windows 10/11 x64、有本机执行权限和首次联网能力的宿主。用户明确禁止下载时遵从其限制并说明哪些功能未就绪，不替用户放宽限制。

## 一次入口

从本 Skill 的真实位置运行 `scripts/first-use.cmd`。可在 PowerShell 7 用 `& "<Skill目录>\scripts\first-use.cmd"`，或由宿主运行该 CMD；不调用 Windows PowerShell 5.1。

该入口自动完成：
1. 复用可运行的 Node.js 24+；缺少时下载校验过的便携 Node.js。缺少 PowerShell 7 时也使用便携版，不需要管理员或系统 PATH 修改。
2. 如果宿主只安装了仓库中的 `skill/`，自动从**本 Skill 对应版本**的 GitHub Release 下载完整包，核对 SHA256SUMS 和包内清单。完整 ZIP 已在当前位置时直接使用；不把模板误当成完整应用，也不临时克隆源码要求用户构建。
3. 检查本机 tools.json 和 PATH 指定的 FFmpeg／FFprobe、whisper.cpp CPU 识别器。复用有效配置；缺项下载固定版本及 multilingual small 模型。文件放在本机资料根的 `runtime/`，不写进公开包或其他项目，不全盘搜工具。已有未知配置字段保留，改动前保留旧配置。
4. 用随包中文语音运行真实解码、波形和字幕生成，检查文字与时间码。通过后保存简短本机回执，删除本轮生成的临时音轨／字幕，不在用户任务列表留下测试条目。
5. 初始化本副本桌面入口和当前用户页面唤起协议，启动／复用校对台，并请求系统浏览器打开。

首次全缺时约下载 0.8 GB，建议有 2 GB 空间；已有工具会复用。下载只用于获取工具和模型，不上传用户素材。联网下载源与版本在 [依赖来源](dependency-sources.md)，不是让 Agent 临时搜索不明下载站。下载失败可重跑同一入口，已完成工具不重复下载。

## 什么时候调用

- 第一次使用、收到缺工具提示、工具配置变化或用户要求重新验证时调用。普通日常命令使用 `scripts/review.cmd`，即使 Node 不在系统 PATH 也能找到便携版。
- 紧接着要送入本轮成片时，先 `scripts/first-use.cmd --no-browser`，成功后按主流程执行 `scripts/review.cmd after-export ...`；由送片步骤打开正确页面，不先后多开两页。
- 用户只是要打开校对台时，直接运行首次入口即可，不再追加 open 或新建浏览器标签。
- 用户明确重新测试时加 `--verify`；其余重复调用会核对版本、工具和样本是否变化，匹配时复用已通过回执，不每次重复识别。
- 不在普通 `doctor`、状态查询或阅读交接意见时偷偷下载；doctor 仅诊断。需要补齐时由 Agent 进入本流程。

## 怎样判断完成

回读标准输出最后一行 JSON：`format=media-review-setup/v1`、`ready=true`、`verification.passed=true`。`verification.reused=true` 表示工具未变化、沿用了此前实测，不描述为刚刚重新识别。

`url` 是共用校对台地址；真实用户素材仍用 after-export 得到独立 taskId 和 taskUrl。`browser.open/requested` 只说明系统开页请求，不证明页面已经可见。宿主有浏览器能力时核对实际页面加载；已有窗口被复用时保持它，不抢正在审的片。系统开页失败时用回执 URL 在宿主中打开，并说明具体障碍，不谎报网页已打开。

识别生成不等于字幕准确、全片人工检查、用户认可或允许发布。仍按主 Skill 自检和逐条返修规则工作。

## 故障只处理当前一步

- 网络／下载校验失败：不执行未验证文件；Agent 检查具体来源和网络后有限重试。不自动改成不明镜像、关闭证书或让用户从头手装所有依赖。
- 自检失败：保留已有工具和旧配置；读取错误阶段，核对 FFprobe、Whisper 与模型能否实际运行。工具文件存在不能代替识别通过。已有明确自选模型时，不能为了通过测试偷偷换成其他模型。
- 原配置损坏、目录含链接或已有未完成内容：保留原件，Agent 核对具体冲突并在原授权内修复，不删用户资料目录来重试。
- 同数据根的旧版本仍运行：先查看旧窗口和未保存工作；安全退出旧版后继续，不能自动结束未知进程。这个冲突不表示下载失败。
- 宿主确实不能运行本机命令、系统架构不支持或网络被外部策略拦截：明确缺少的那项能力与影响。只在确实需要人的权限／材料时要求最小操作，不把整体配置责任推给用户。

## 非默认安装与隔离测试

完整包安装到宿主指定 Skill 目录：`scripts/first-use.cmd --install --destination "<完整Skill目录>"`。已被宿主放进正确目录的包直接准备，不再默认复制到 Claude 目录。

已有明确工具可加 `--ffmpeg`、`--whisper`、`--model` 绝对路径；这是 Agent 接入已有环境的参数，普通用户不用填写。指定无效时保留原配置并报告，不静默改用其他工具。

隔离测试先设置绝对路径 `MEDIA_REVIEW_DATA_DIR`，可加 `--desktop-dir "<隔离快捷方式目录>"`，需要跳过协议时加 `--skip-page-launcher`。测试结束只退出该数据根服务，注销本次注册的协议并清理测试目录；不删除真实用户任务、既有模型或共享工具。随包自检样本属于产品资源，不是待删除的临时测试产物。
