# Media Review Skill

Agent 出片后主动打开本机音视频校对室，并在制作循环中自检；你按时间或画面位置留下意见，保存后交回 Agent 返修。也能审阅其他软件制作的成片，校对室本身不改写原片。

## Windows 安装

需要 Node.js 24+、PowerShell 7+（`pwsh`，不是 Windows PowerShell 5.1）以及支持素材编码的浏览器。

拿到完整 ZIP 后，解压并双击[安装 Media Review.cmd](安装%20Media%20Review.cmd)。安装器默认将完整包安装到当前用户的 `.claude/skills/media-review`，并创建“Media Review”桌面入口；不需要管理员权限，不自动下载软件、注册开机启动或修改其他 Skill。已有不同版本或本机修改会保留并停止，不静默覆盖。

如果你是在源码仓库的 `skill/` 下看到本文件，这里只是打包模板，缺少运行程序和清单，不能直接当成完整安装包。

仅复制完整包到 Skill 目录不会运行安装器；首次运行[初始化桌面入口.cmd](初始化桌面入口.cmd)补建图标。其他本机宿主可用安装器的 `-Destination` 指定**本 Skill 包自身的完整目标目录**，例如 `<宿主的skills目录>\media-review`；不要只填上一级 `skills` 父目录，安装器不会自动补一层项目名。是否自动发现 Skill 由宿主负责。

日常双击桌面图标即可按需启动或复用服务。选择视频／音频，标记一个时间点，写意见并保存，就能在首页历史中查看记录和真实保存位置。不需要运行 npm 或保持终端窗口。

## Agent 出片后主动调用

本 Skill 已进入任务且 Agent 有本机文件／进程权限时，从本 Skill 目录执行：

```sh
node scripts/review.mjs after-export --media "<已经写入完成的成片绝对路径>"
```

它实际启动服务、登记明确文件、打开校对室并产生独立自检资料，不等待用户再说“打开”，也不是对任意剪辑软件的后台监控。Agent 仍需实际看画面或听声音，不能把取帧、统计或退出码当成全片或美感验收。已有用户草稿时，新版本只提示，不强制换片。

## 保存与交接

标记时间点、共同时间段或当前帧区域，写“修改／保留／待讨论”。单条保存写入回读成功后空白新建；整轮完成点击“保存并交给 Agent”，会包含最后完整草稿。复制后回到能读取本机资料的 Agent 聊天并实际发送，才交由它按意见返修；保存或复制不自动剪辑、上传或发布。

“校对历史”区分正式意见与恢复草稿，可以打开记录／参考图文件夹。没有Agent或要交给剪辑人员时，先正式保存这一轮、关闭交接弹窗返回当前素材，再点击右侧意见栏底部的“导出返修资料包”。在导出弹窗复制实际文件夹位置，把整个资料文件夹交给对方，并另行提供正确源媒体；此操作不需要查找指纹。资料包包含清单、结构化意见与相对路径参考图，不默认附带原视频、其他轮次或自动执行授权。

## 工具、数据与断线

FFmpeg／FFprobe、Whisper CLI 和离线模型均为可选工具，不随包提供或自动下载。缺少时仍可播放、手动标注、保存和交接，波形／转写和工具自检会明确显示不可用或未验证。用 `node scripts/review.mjs doctor` 查看可用性；安装器可显式绑定已有工具。

默认私有数据位于用户主目录的 `.media-review-desk/data`，历史名称保留以兼容已有资料，与程序分开。Agent 自检与用户意见分开保存；恢复副本不是正式保存。应用不内置云端上传；交接给云端 Agent 时仍需按宿主的数据政策处理。

服务只监听 `127.0.0.1`，默认 30 分钟无实际操作或最长 4 小时关闭。出现红色断开／会话失效提示时，保留旧页，不要刷新或关闭，从桌面重新进入。Agent 登记的原文件可自动重开；手选文件需重新选择同一文件再恢复。最后未确认输入、清理浏览器数据、源文件变化或任意端口冲突不能保证零损失。
