# Media Review Skill

Agent出片后主动送到本机音视频校对室并排队自检；你回来后从任务列表接手，按时间或画面位置留下意见，再交回Agent返修。校对室本身不改写原片，也能审阅其他软件制作的成片。

这是 **0.3.0-beta.6 Windows 预发布完整包**，包含连续标注、逐条返修与新版复核。[本版发布页](https://github.com/Ww-Cooooo/media-review/releases/tag/v0.3.0-beta.6)提供完整 ZIP 和校验文件；旧版安装不会自动更新，升级请先保存、备份并核对新入口。

## 边看边记意见

播放到问题开始时点“标记起点”，继续观看，到结束时点“标记终点”；同一时间段可继续框选当前画面，添加多个稳定编号框。画面缩放、放大和全屏继续可用。

- **整片意见**：在意见栏点“整片意见 · 不限时间”，可以先写想法再选择范围，保存后列在时间标注之前。
- **没有意见也能完成**：点“审阅完毕，没有意见”，会保存本轮审阅结果和完成时间，并生成可复制的交接内容。普通“保存进度”不会自动记作审阅完成。审阅结果与任务是否继续等待是两个状态；需要结束等待时仍用“任务操作 → 结束当前任务”。
- **搜索任务**：首页或“校对任务”中可按任务名、来源、文件名、任务编号查找，必要时打开“包含已结束任务”。搜索覆盖全部登记任务。
- **修正框选**：可以按编号删除任意框，撤销或重做当前编辑内的最近 30 次新增、移动、缩放和删除。删除不会重排其他编号；保存和重开后也不会复用已用过的最大编号。意见栏中的文字不会随几何撤销而消失；输入框保留自己的文字撤销。
- **恢复误删意见**：移除意见后点“撤销删除意见”。此恢复保留到当前素材关闭或页面重开前，恢复后需要保存。
- **同屏校对**：在 1366×768 桌面上，常用播放／标记控件与意见输入及保存按钮可以同屏使用；长意见、坐标详情和更多记录仍可滚动查看。暂停定位后的缩放画面会跟随实际解码帧刷新。

### 记录与返修

新记录采用 `ai-carry-media-review/v5`，继续读取 v1／v2／v3／v4；旧版首次升级保存时保留原字节备份，不批量转换既有资料。新恢复副本采用 `media-review-workspace/v4`，继续读取旧恢复格式。

`scope: "whole"` 表示整片意见，`startMs` 和 `endMs` 为 `null`，不能当作第 0 秒。带 `reference` 的整片意见可以附带举例画面；参考帧仍独立于范围。`regions` 保留编号与归一化坐标，`regionSerial` 记录已分配的最大编号。

`completion.outcome: "no-changes"` 只表示用户明确完成了这轮审阅且没有意见，不能推导发布许可或要求 Agent 虚构返修；`with-notes` 表示已完成并留下意见，`null` 或缺失表示未记录完成。新增或修改后普通保存会清除旧的完成结果，需再次明确完成。完成结果可重读和导出。

程序回退前先备份新增记录和返修进度。旧程序不认识 v5，应继续使用此版或恢复匹配的应用，不要用旧记录覆盖后来新增的意见。


## Windows 安装

自动准备支持 Windows 10/11 x64 和 Edge／Chrome。首次需要联网；Node.js 24、PowerShell 7、FFmpeg／FFprobe、Whisper CPU 与 small 多语种模型由 Agent 调用首次入口准备，不要求用户自行下载或填写路径。

已经由宿主安装好本 Skill 时，让 Agent 运行 `scripts/first-use.cmd`。它优先复用已有工具，下载并校验缺项，完成真实中文字幕测试后创建桌面入口、注册当前用户页面唤起协议，并打开网页。工具放在本机私有目录，不需要管理员权限、不改系统 PATH、不开机自启。已有本机修改或其他版本保留，Agent 处理对应冲突。

如果宿主安装的是仓库中的整个 `skill/`，首次入口会从对应版本的 GitHub Release 自动下载完整应用并校验。不能只复制 SKILL.md；脚本、参考和自检样本也需要保留。

手动下载完整 ZIP 的用户可双击[安装 Media Review.cmd](安装%20Media%20Review.cmd)，默认安装到 `.claude/skills/media-review`。其他宿主由 Agent 使用 `scripts/first-use.cmd --install --destination "<宿主的skills目录>\media-review"`。已经放在正确 Skill 目录时直接运行首次入口或[初始化桌面入口.cmd](初始化桌面入口.cmd)，无需再复制。完整流程、故障处理与回执说明见[首次准备](references/first-use.md)。

日常双击桌面入口按需启动或复用服务。选择视频／音频，标记时间、写意见并保存，在首页“校对任务”点“查看资料”找到正式记录；不需要npm或一直开着终端。继续已有任务请从列表进入，需要另一套独立意见时点“手选素材，新建独立任务”。

## Agent 出片后主动调用

本 Skill 已进入任务且 Agent 有本机文件／进程权限时，从本 Skill 目录执行：

```sh
scripts/review.cmd after-export --media "<已经写入完成的成片绝对路径>" --request-id "<本轮固定UUID>" --label "<来源短标识>"
```

入口返回独立taskId，并将自检送入共享队列，不等于已经检查完成。同次调用重试用相同`--request-id "<UUID>"`，新版本或独立意图用新UUID；用`status --task "<taskId>" --job "<inspection.id>" --result`读取这次实际结果。自检失败后可用`self-check --media "<原路径>" --request-id "<原taskId>" --label "<原task.label>" --title "<原task.title>"`重试同一任务（标题和来源与原回执相同，原来源为空时省略`--label`）；活动分析沿用原job，已终止分析返回新job，完成结果仍可能经完整内容校验后复用缓存。不是文件监控，不安装全局hook。

同用户、同数据根共用兼容服务。一次运行首次自动请求打开浏览器，之后只送任务，不抢当前片；Agent不能拿到网址后再新建一页证明送达。回执中的`taskUrl`定位本轮独立任务，`url`只是共用入口；用户明确重开这项任务时使用`scripts/review.cmd open --task "<taskId>"`，不重新登记成片。任务专属链接在次窗口也按指定任务打开；同任务有编辑窗口时仍先询问只读，不抢编辑。手动切换任务后网址同步到当前任务，不因后来送片改变。普通桌面或`open`只打开共用校对室，可能新开页，不能强制聚焦旧tab。Skill是宿主调用指引，不是所有宿主的强制拦截器。实际查看／回听与工具证据分开报告，Agent做完后不默认退出全局服务。

### 放大和全屏看视频

视频播放条右侧提供“放大”和“全屏”。放大占用当前网页的可用空间，全屏调用浏览器Fullscreen API；按Esc、“收起”或“退出全屏”返回。沿用同一个视频节点，不重新下载或分析，保留播放位置、速度和未保存意见。浏览器拒绝系统全屏时会明确提示并改用页内放大；纯音频和“只听声音”模式不显示视频全屏入口。放大后完成画面标注，会先返回意见栏再输入；坐标仍相对完整视频画幅，不按留白计算。

## 保存与交接

标记时间点、共同时间段或当前帧区域，写“修改／保留／待讨论”。单条保存写入回读成功后空白新建；整轮完成点击“完成审阅并交接”，会包含最后完整草稿。复制后回到能读取本机资料的 Agent 聊天并实际发送，才交由它按意见返修；保存或复制不自动剪辑、上传或发布。

任务列表显示来源与实际分析状态，各任务意见分别保存。任务ID和来源不自动绑定或唤醒原聊天，请将交接发到负责此任务的对话；本应用没有整片认可或发布按钮，不把保留项或结束任务记作通过。同一任务默认一个编辑窗口；其他窗口需明确只读或接管，保存仍核对加载版本。冲突先比对，不自动合并，明确替换时保留正式旧版；恢复副本的基线变化也须选择。旧资料仍可从“旧版校对历史”查看，不自动改成新的采用意图。没有Agent或要交给剪辑人员时，先正式保存这一轮、关闭交接弹窗返回当前素材，再点击右侧意见栏底部的“导出返修资料包”。在导出弹窗复制实际文件夹位置，把整个资料文件夹交给对方，并另行提供正确源媒体；此操作不需要查找指纹。资料包包含清单、结构化意见与相对路径参考图，不默认附带原视频、其他轮次或自动执行授权。

## 工具、数据与断线

首次入口会自动准备 FFmpeg／FFprobe、Whisper CLI 和离线模型，优先复用本机已有绑定。用 `scripts/review.cmd doctor` 查看可用性。首次下载中断时，Agent 应修复具体失败项并重试；播放、手动标注、保存和交接不依赖识别器，自动转写只有实际测试通过后才算就绪。

默认私有数据位于用户主目录的 `.media-review-desk/data`，历史名称保留以兼容已有资料，与程序分开。Agent 自检与用户意见分开保存；恢复副本不是正式保存。应用不内置云端上传；交接给云端 Agent 时仍需按宿主的数据政策处理。

服务只监听`127.0.0.1`。有待人工任务、窗口或分析时不按旧30分钟／4小时退出；真正空台默认10分钟回收。挂起卸载本页媒体，任务继续等人；结束任务不删除／认可；退出整个服务需明确确认。最多一个重分析，32个活跃排队项、2份上传；可重建缓存有容量，正式意见与草稿不自动删除，达到保存预算时明确提示整理而不是悄悄丢弃。

活跃队列满可等待或撤回自己的分析需求；历史登记、恢复归档或浏览器预算满，目前没有内置安全批量整理工具。先正式保存／回读并备份，保留未确认输入，不批量删除意见或浏览器数据库。确需继续新工作时，可明确退出旧服务后指定新的绝对路径`MEDIA_REVIEW_DATA_DIR`隔离新任务；原根保留，不自动迁移旧任务或草稿，也不代表旧工作已经完成。

出现“暂无法连接”时保留旧页，不要刷新有未保存输入的页面。页头连接状态右侧显示“重启服务”。安装器已配置本数据根启动协议时，它与下方断线提示内的“启动 Media Review 本机校对室”使用同一个入口，请求Windows唤起本机Node服务；等待期间共同防止重复点击，恢复核验通过后页头按钮自动收起。未配置或版本不匹配时按钮禁用，不强行关闭其他服务；未配置时用桌面或[启动 Media Review 本机音视频校对室.cmd](启动%20Media%20Review%20本机音视频校对室.cmd)。服务在线时，“任务操作 → 重启校对服务”先核对共用窗口、分析和未保存输入；确认后准备接续入口再退出旧服务，未完成分析可能中断，页面恢复后可能重新排队，不把旧分析当完成。“退出整个校对室”仍只退出，不自动重启。恢复需重新核验身份、认证、编辑权限与意见版本；原端口被占用时可能打开新地址，不能保证旧页无条件重连。

### 正在分析哪个素材

本版会在页面左下角显示可收起的分析提示，列出本服务当前处理／排队／上传的素材、真实阶段、校对任务与服务地址。点击素材会核验状态并请求定位已打开的对应校对页；浏览器未允许切页时，可在本页只读定位，原页分析不取消、不重复开浏览器。本页未保存输入仍需先处理；手选媒体需要重选同一版本。收起不停止分析，断线或状态查询失败不把旧状态当成仍在运行。范围仅限本服务登记的任务，不扫描其他网页或程序；未知来源明确标明，不能保证浏览器允许切换标签页。

### 启动用途、安全软件与协议登记

入口明确说明“启动 Media Review 本机音视频校对室”，实际调用安装时选定的Node.js，不上传素材，不增加常驻启动器或开机自启。协议按资料根隔离，只接受固定start动作，不接收网址中的任意命令、程序路径或媒体路径。浏览器可能弹出打开本机应用的确认；系统仍可能显示Node.js、脚本程序或未知发布者。请核对来源、安装路径与拦截详情，不要关闭防护或随意加入排除。完整说明见[启动入口说明.txt](启动入口说明.txt)。

不希望注册协议时，运行`pwsh -NoProfile -File .\scripts\install.ps1 -Destination "<新的完整安装目录>" -SkipPageLauncher`，只跳过本次注册，不取消已有登记。另一Media Review副本已有登记时默认保留；明确采用新副本时才加`-ReplacePageLauncher`，未知归属的协议即使加参数也不覆盖。自定义资料根应先设置绝对路径`MEDIA_REVIEW_DATA_DIR`，启动入口会固定绑定这个根，不依赖浏览器继承终端环境。

以下低层命令中的 `pwsh` 若不在系统 PATH，由 Agent 使用首次入口最后一行 JSON 中 `pwsh` 给出的绝对路径执行；无需用户再安装 PowerShell。

取消本安装副本的页面入口，可从其完整目录执行：

```powershell
pwsh -NoProfile -File .\scripts\page-launcher.ps1 -Action Unregister -AppRoot "<本安装完整目录>\app" -DataRoot "<原登记的资料根，不含末尾data>" -Node "<原登记的node.exe绝对路径>"
```

默认资料根是用户主目录的`.media-review-desk`；原登记路径可在其`data/native-launcher.json`核对。命令核对归属，不取消其他安装副本的登记，不关闭服务、不删除意见；移动或删除安装前先取消本入口。源文件可重新带入，移动后可“手选同版”；原本手选的文件也需重选。最后未确认输入、清理浏览器数据、原文件变化或未知端口冲突下不能保证零损失。

### 旧版升级

先在旧页保存并备份整个`.media-review-desk/data`及原媒体，再安装到新的完整目录。不兼容旧服务仍运行时，新入口会拒绝，不自动关闭它。beta.2可从旧页“任务操作 → 退出整个校对室”明确退出；beta.1没有界面退出按钮：从新包目录先执行`scripts/review.cmd quit-legacy --legacy-root "<旧包app目录的绝对路径>"`核对，确认旧窗口已保存且要退出后才追加`--confirm`。只处理session登记的已知旧服务，不扫描／结束未知PID，也不保证未登记重复服务或独立CLI都已退出；无法核实则用新的绝对路径`MEDIA_REVIEW_DATA_DIR`隔离试用，不能混跑默认数据根。让宿主显式使用选定的新Skill路径，桌面图标以安装器回执为准，不能假称已替换旧安装。

## 完整校对与返修

这些功能已包含在本版完整安装包中。

- 首页按名称、来源、文件名或任务编号搜索；按待校对、已结束、归档或全部筛选，按最近送达/打开排序。可以重命名、批量归档和恢复。归档保留意见与版本关系；恢复到历史列表后可重开任务继续，正在窗口中打开的任务会跳过归档。
- 边看边按 I 标起点、O 标终点。空格播放/暂停；左右方向键跳一秒，Shift+方向键或逗号/句号按所选毫秒细步。回放选段可带前后 0.5/1/2 秒；这不承诺逐帧精度。
- 时间段可同时有独立参考帧及多个稳定编号框。点击框和说明可相互定位；每框可选填说明，仍可用一段共用意见。删框不重排编号，几何撤销不回退已输入的文字。
- 意见清单按关键词、问题类别和处理进度筛选，N 跳到下一条当前筛选的问题。台词栏支持关键词搜索和 UTF-8 SRT/WebVTT 导入；导入字幕按任务保存，时间异常提示核对，不自动挪动时间码。
- 顶部“版本与返修”显示同作品 V1/V2、各版意见与本版处理内容。手选新版本或 Agent 用 previous-task 登记关系；旧时间码、截图和框仍属于原版。返修可定位到明确的新位置，用户复核确认后仍可重新打开问题。
- “修改/保留/待讨论”表示意见性质；返修进度单独保存。意见文字或区域被修改时，原处理结果转为需要重新核对，历史仍在。Agent 只能提交结果待复核，不能代用户确认。
- 完成审阅生成不可变的本轮交接快照，包含 taskId、意见修订、版本与来源。零意见也可明确完成；审阅完成、结束等待、用户确认和发布许可分别表达。
- 恢复/保存冲突逐条显示文字、时间、参考帧和画面框差异；可按条保留并回到编辑，再明确保存。旧副本与未保存草稿继续保留。
- 导出含可直接打开/打印的 `返修清单.html`、文字清单、带编号框且内嵌原图的 `annotated/*.svg`、未修改的 `references/` 和 `review.json`。不含原视频或音频、不自动上传；SVG 可独立查看，坐标和分框文字可继续由 Agent 读取。
