# Media Review Skill

Agent出片后主动送到本机音视频校对室并排队自检；你回来后从任务列表接手，按时间或画面位置留下意见，再交回Agent返修。校对室本身不改写原片，也能审阅其他软件制作的成片。

这是 **0.3.0-beta.4 Windows预发布完整包**，桌面启动入口采用透明底小电视IP图标；页面重启与Windows本机唤起、分析浮窗定位、任务专属入口和视频放大／全屏沿用beta.3。[本版发布页](https://github.com/Ww-Cooooo/media-review/releases/tag/v0.3.0-beta.4)提供完整ZIP和校验文件；旧版安装不会自动更新，升级请先保存、备份并核对新入口。

## Windows 安装

需要 Node.js 24+、PowerShell 7+（`pwsh`，不是 Windows PowerShell 5.1）以及支持素材编码的浏览器。

拿到本版的完整 ZIP 后，解压并双击[安装 Media Review.cmd](安装%20Media%20Review.cmd)。安装器默认将完整包安装到当前用户的 `.claude/skills/media-review`，创建采用随包小电视IP图标的“Media Review”桌面入口，并注册当前用户、按资料根隔离的页面启动协议。入口说明明确为“启动 Media Review 本机音视频校对室”，实际启动本机Node.js服务；不需要管理员权限，不自动下载软件、注册开机启动或修改其他 Skill。已有不同版本或本机修改会保留并停止，不静默覆盖。

如果你是在源码仓库的 `skill/` 下看到本文件，这里只是打包模板，缺少运行程序和清单，不能直接当成完整安装包。

仅复制完整包到 Skill 目录不会运行安装器；首次运行[初始化桌面入口.cmd](初始化桌面入口.cmd)补建图标。其他本机宿主可用安装器的 `-Destination` 指定**本 Skill 包自身的完整目标目录**，例如 `<宿主的skills目录>\media-review`；不要只填上一级 `skills` 父目录，安装器不会自动补一层项目名。是否自动发现 Skill 由宿主负责。

日常双击桌面入口按需启动或复用服务。选择视频／音频，标记时间、写意见并保存，在首页“校对任务”点“查看资料”找到正式记录；不需要npm或一直开着终端。继续已有任务请从列表进入，需要另一套独立意见时点“手选素材，新建独立任务”。

## Agent 出片后主动调用

本 Skill 已进入任务且 Agent 有本机文件／进程权限时，从本 Skill 目录执行：

```sh
node scripts/review.mjs after-export --media "<已经写入完成的成片绝对路径>" --request-id "<本轮固定UUID>" --label "<来源短标识>"
```

入口返回独立taskId，并将自检送入共享队列，不等于已经检查完成。同次调用重试用相同`--request-id "<UUID>"`，新版本或独立意图用新UUID；用`status --task "<taskId>" --job "<inspection.id>" --result`读取这次实际结果。自检失败后可用`self-check --media "<原路径>" --request-id "<原taskId>" --label "<原task.label>" --title "<原task.title>"`重试同一任务（标题和来源与原回执相同，原来源为空时省略`--label`）；活动分析沿用原job，已终止分析返回新job，完成结果仍可能经完整内容校验后复用缓存。不是文件监控，不安装全局hook。

同用户、同数据根共用兼容服务。一次运行首次自动请求打开浏览器，之后只送任务，不抢当前片；Agent不能拿到网址后再新建一页证明送达。回执中的`taskUrl`定位本轮独立任务，`url`只是共用入口；用户明确重开这项任务时使用`node scripts/review.mjs open --task "<taskId>"`，不重新登记成片。任务专属链接在次窗口也按指定任务打开；同任务有编辑窗口时仍先询问只读，不抢编辑。手动切换任务后网址同步到当前任务，不因后来送片改变。普通桌面或`open`只打开共用校对室，可能新开页，不能强制聚焦旧tab。Skill是宿主调用指引，不是所有宿主的强制拦截器。实际查看／回听与工具证据分开报告，Agent做完后不默认退出全局服务。

### 放大和全屏看视频

视频播放条右侧提供“放大”和“全屏”。放大占用当前网页的可用空间，全屏调用浏览器Fullscreen API；按Esc、“收起”或“退出全屏”返回。沿用同一个视频节点，不重新下载或分析，保留播放位置、速度和未保存意见。浏览器拒绝系统全屏时会明确提示并改用页内放大；纯音频和“只听声音”模式不显示视频全屏入口。放大后完成画面标注，会先返回意见栏再输入；坐标仍相对完整视频画幅，不按留白计算。

## 保存与交接

标记时间点、共同时间段或当前帧区域，写“修改／保留／待讨论”。单条保存写入回读成功后空白新建；整轮完成点击“保存并交给 Agent”，会包含最后完整草稿。复制后回到能读取本机资料的 Agent 聊天并实际发送，才交由它按意见返修；保存或复制不自动剪辑、上传或发布。

任务列表显示来源与实际分析状态，各任务意见分别保存。任务ID和来源不自动绑定或唤醒原聊天，请将交接发到负责此任务的对话；本应用没有整片认可或发布按钮，不把保留项或结束任务记作通过。同一任务默认一个编辑窗口；其他窗口需明确只读或接管，保存仍核对加载版本。冲突先比对，不自动合并，明确替换时保留正式旧版；恢复副本的基线变化也须选择。旧资料仍可从“旧版校对历史”查看，不自动改成新的采用意图。没有Agent或要交给剪辑人员时，先正式保存这一轮、关闭交接弹窗返回当前素材，再点击右侧意见栏底部的“导出返修资料包”。在导出弹窗复制实际文件夹位置，把整个资料文件夹交给对方，并另行提供正确源媒体；此操作不需要查找指纹。资料包包含清单、结构化意见与相对路径参考图，不默认附带原视频、其他轮次或自动执行授权。

## 工具、数据与断线

FFmpeg／FFprobe、Whisper CLI 和离线模型均为可选工具，不随包提供或自动下载。缺少时仍可播放、手动标注、保存和交接，波形／转写和工具自检会明确显示不可用或未验证。用 `node scripts/review.mjs doctor` 查看可用性；安装器可显式绑定已有工具。

默认私有数据位于用户主目录的 `.media-review-desk/data`，历史名称保留以兼容已有资料，与程序分开。Agent 自检与用户意见分开保存；恢复副本不是正式保存。应用不内置云端上传；交接给云端 Agent 时仍需按宿主的数据政策处理。

服务只监听`127.0.0.1`。有待人工任务、窗口或分析时不按旧30分钟／4小时退出；真正空台默认10分钟回收。挂起卸载本页媒体，任务继续等人；结束任务不删除／认可；退出整个服务需明确确认。最多一个重分析，32个活跃排队项、2份上传；可重建缓存有容量，正式意见与草稿不自动删除，达到保存预算时明确提示整理而不是悄悄丢弃。

活跃队列满可等待或撤回自己的分析需求；历史登记、恢复归档或浏览器预算满，目前没有内置安全批量整理工具。先正式保存／回读并备份，保留未确认输入，不批量删除意见或浏览器数据库。确需继续新工作时，可明确退出旧服务后指定新的绝对路径`MEDIA_REVIEW_DATA_DIR`隔离新任务；原根保留，不自动迁移旧任务或草稿，也不代表旧工作已经完成。

出现“暂无法连接”时保留旧页，不要刷新有未保存输入的页面。页头连接状态右侧显示“重启服务”。安装器已配置本数据根启动协议时，它与下方断线提示内的“启动 Media Review 本机校对室”使用同一个入口，请求Windows唤起本机Node服务；等待期间共同防止重复点击，恢复核验通过后页头按钮自动收起。未配置或版本不匹配时按钮禁用，不强行关闭其他服务；未配置时用桌面或[启动 Media Review 本机音视频校对室.cmd](启动%20Media%20Review%20本机音视频校对室.cmd)。服务在线时，“任务操作 → 重启校对服务”先核对共用窗口、分析和未保存输入；确认后准备接续入口再退出旧服务，未完成分析可能中断，页面恢复后可能重新排队，不把旧分析当完成。“退出整个校对室”仍只退出，不自动重启。恢复需重新核验身份、认证、编辑权限与意见版本；原端口被占用时可能打开新地址，不能保证旧页无条件重连。

### 正在分析哪个素材

本版会在页面左下角显示可收起的分析提示，列出本服务当前处理／排队／上传的素材、真实阶段、校对任务与服务地址。点击素材会核验状态并请求定位已打开的对应校对页；浏览器未允许切页时，可在本页只读定位，原页分析不取消、不重复开浏览器。本页未保存输入仍需先处理；手选媒体需要重选同一版本。收起不停止分析，断线或状态查询失败不把旧状态当成仍在运行。范围仅限本服务登记的任务，不扫描其他网页或程序；未知来源明确标明，不能保证浏览器允许切换标签页。

### 启动用途、安全软件与协议登记

入口明确说明“启动 Media Review 本机音视频校对室”，实际调用安装时选定的Node.js，不上传素材，不增加常驻启动器或开机自启。协议按资料根隔离，只接受固定start动作，不接收网址中的任意命令、程序路径或媒体路径。浏览器可能弹出打开本机应用的确认；系统仍可能显示Node.js、脚本程序或未知发布者。请核对来源、安装路径与拦截详情，不要关闭防护或随意加入排除。完整说明见[启动入口说明.txt](启动入口说明.txt)。

不希望注册协议时，运行`pwsh -NoProfile -File .\scripts\install.ps1 -Destination "<新的完整安装目录>" -SkipPageLauncher`，只跳过本次注册，不取消已有登记。另一Media Review副本已有登记时默认保留；明确采用新副本时才加`-ReplacePageLauncher`，未知归属的协议即使加参数也不覆盖。自定义资料根应先设置绝对路径`MEDIA_REVIEW_DATA_DIR`，启动入口会固定绑定这个根，不依赖浏览器继承终端环境。

取消本安装副本的页面入口，可从其完整目录执行：

```powershell
pwsh -NoProfile -File .\scripts\page-launcher.ps1 -Action Unregister -AppRoot "<本安装完整目录>\app" -DataRoot "<原登记的资料根，不含末尾data>" -Node "<原登记的node.exe绝对路径>"
```

默认资料根是用户主目录的`.media-review-desk`；原登记路径可在其`data/native-launcher.json`核对。命令核对归属，不取消其他安装副本的登记，不关闭服务、不删除意见；移动或删除安装前先取消本入口。源文件可重新带入，移动后可“手选同版”；原本手选的文件也需重选。最后未确认输入、清理浏览器数据、原文件变化或未知端口冲突下不能保证零损失。

### 旧版升级

先在旧页保存并备份整个`.media-review-desk/data`及原媒体，再安装到新的完整目录。不兼容旧服务仍运行时，新入口会拒绝，不自动关闭它。beta.2可从旧页“任务操作 → 退出整个校对室”明确退出；beta.1没有界面退出按钮：从新包目录先执行`node scripts/review.mjs quit-legacy --legacy-root "<旧包app目录的绝对路径>"`核对，确认旧窗口已保存且要退出后才追加`--confirm`。只处理session登记的已知旧服务，不扫描／结束未知PID，也不保证未登记重复服务或独立CLI都已退出；无法核实则用新的绝对路径`MEDIA_REVIEW_DATA_DIR`隔离试用，不能混跑默认数据根。让宿主显式使用选定的新Skill路径，桌面图标以安装器回执为准，不能假称已替换旧安装。
